## Gickup Guard v0.1.0

**Verify that your recent GitHub changes reached GitLab.**

This first public release wraps [Gickup](https://github.com/cooperspencer/gickup) with an incremental preflight, SHA-based postflight, and a retry queue that survives beyond the configured activity window.

### Included

- Compare selected GitHub and GitLab branch/tag refs by SHA before transferring.
- Run Gickup only for missing or mismatched repositories.
- Verify the original snapshot after transfer; leave incomplete transfers in the retry queue.
- Store reports and retry artifacts in the **private repository running the Action**.
- Configure a personal GitHub account plus optional organizations with fictional example config/workflow.
- TypeScript code with synthetic unit tests and no external server.

### Scope and limitations

GitHub.com → private GitLab.com mirrors. Verification covers selected Git refs, not arbitrary Git objects, LFS, GitHub Issues, pull requests, releases, or restore drills. Repositories outside the activity window and retry queue are not audited. This is a tool for maintaining **Git mirrors**, not a comprehensive GitHub account archive.

### First run

Copy [the example configuration](../../tree/v0.1.0/examples/config.json) and [workflow](../../tree/v0.1.0/examples/backup.yml) into a **private caller repository**, add tokens as Actions secrets, then run the workflow manually. See [README](../../tree/v0.1.0/README.md) for required permissions, token scope and safety limitations.
